# Indian Global Entry Program Background Verification Requirements — USA

Run only when the service family is `global_entry_background_verification`.

## Sequence gates

1. Applicant has initiated the U.S. Customs and Border Protection Global Entry application.
2. Applicant completes the Government of India Passport Seva GEP/background-verification application using the required reference information.
3. Applicant prepares the current physical GEP package for VFS.

## Core documents currently identified by CGI San Francisco

- printed Government GEP application;
- copy of current Indian passport;
- proof of present address;
- current applicable fee/payment evidence;
- any additional current VFS GEP checklist items for the applicant's jurisdiction.

## Timing guardrail

The Consulate states that no fixed processing timeline is defined because multiple Government departments participate in vetting. Never promise a completion date from this bundle; represent timing as dependent on Government background verification.
