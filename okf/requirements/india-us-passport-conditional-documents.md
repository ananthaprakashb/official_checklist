# Conditional Re-issue Documents — USA

Add only the requirements triggered by applicant facts and the selected Re-issue reason.

## Lost or damaged passport

- use the branch-specific lost/damaged checklist;
- include Annexure F;
- apply the lost/damaged fee tier;
- preserve any additional police/report/explanation requirements specified by the current checklist at execution time.

## Name / spouse-name changes

Depending on the exact change, current checklist examples include marriage certificate, joint photo declaration, divorce decree/order, death certificate of prior spouse, re-marriage evidence, notarized affidavit of name change, newspaper publication and/or public/school records for name changes outside marriage/remarriage/divorce.

## Indian address change

Use acceptable Indian address evidence from the current checklist, such as Aadhaar, eligible bank statement/passbook, driver's licence, qualifying utility bill, voter ID, ration card, or qualifying parent/relative address evidence.

## Parent-name change

Current adult checklist calls for supporting public documents carrying the corrected/new parent name; date/place-of-birth or parent-name correction cases may require additional civil/school/court/competent-authority evidence.

## Date/place of birth correction

Do not reduce this to a generic upload. Route to authoritative-review mode and require the exact documentary branch in the current checklist. Tatkaal is not available for current DOB/POB correction categories.

## Appearance/signature change

Record the change explicitly and require the appearance/signature affidavit and any current notarization rules. Adult appearance/signature-change cases are not Tatkaal eligible under current CGI guidance; minors have different Tatkaal treatment for appearance/signature changes.
