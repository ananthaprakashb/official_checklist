# Immigrant Petition Stage Requirements

## I-140 path

- Select the exact EB-1, EB-2 or EB-3 petition classification before assembling evidence.
- Attach the certified labor certification when the selected category requires ordinary PERM and ensure it is still valid for submission.
- Use the Schedule A procedure when that exception applies rather than presenting an ordinary DOL-certified PERM.
- Preserve the petition's adjustment-versus-consular destination and priority-date basis.
- Treat EB-1A and EB-2 NIW self-petition/job-offer exceptions according to their category-specific rules rather than borrowing an employer/PERM checklist.

## Non-I-140 branches

- EB-4 uses a category-specific special-immigrant petition path rather than Form I-140.
- EB-5 uses Form I-526 or I-526E as applicable rather than Form I-140.

## Final gate

An approved immigrant petition is a petition milestone, not automatic permission to file I-485 or immediate authority for immigrant-visa issuance. Run the visa-number/final-processing gates next.
