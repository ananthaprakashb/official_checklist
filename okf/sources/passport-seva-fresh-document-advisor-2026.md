# Passport Seva Fresh Passport Document Advisor

Authoritative document-advisor entry point for Fresh Passport applications.

The advisor branches on application type (Normal/Tatkaal), applicant category (Minor/Adult/Senior Citizen) and other applicant facts. This bundle uses it as the authoritative source for the existence of category-specific fresh-passport document requirements rather than assuming the re-issue checklist applies.
