# California DMV REAL ID

Primary source for California REAL ID driver-license and identification-card applications.

Key controls encoded by the runtime:

- REAL ID requires proof of identity, Social Security number information subject to applicable exceptions, and two California residency documents;
- if the identity document does not show the applicant's current true full legal name, certified name-trace/change evidence is required;
- applicants can start online and upload documents, but must bring original qualifying documents and complete the process at a DMV office;
- a federal-noncompliant California DL/ID is not a substitute for REAL ID or another federally accepted ID for domestic-airline/security-facility purposes after May 7, 2025;
- AB 60 driver-license applicants are not eligible for REAL ID.
