# VFS USA Passport Application Guidance — August 2026

Current outsourced-service-provider guidance for Indian passport applications in the United States.

Key facts relied on by this bundle:

- U.S. applicants submit passport applications through VFS Indian Consular Application Centres according to consular jurisdiction.
- Government Passport Seva application is completed first.
- Online photograph and signature upload is mandatory; courier applications without the required upload are returned unprocessed.
- Applicants must explicitly select Change in Existing Personal Particulars when details differ from the current passport.
- Supporting documents must match the applicable VFS checklist.
- VFS currently supports postal/courier and appointment/in-person flows, with the exact route selected in the VFS registration process.
- Current ICAO guidance calls for a color 630x810-pixel image with a white background and unaltered appearance.
