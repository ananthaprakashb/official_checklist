# California DMV Driver Licenses

Primary source for first-time California driver licenses, under-18 licensing, transfers from another U.S. state or another country, testing, identity/residency requirements, and REAL ID versus federal-noncompliant licensing.

Key controls encoded by the runtime:

- a new California resident with a valid license from another U.S. state follows California's original-license application process and DMV testing requirements;
- a license issued by another country follows that process and additionally requires a behind-the-wheel drive test;
- first-time drivers use an instruction-permit path before the drive test;
- under-18 applicants have separate provisional permit/license milestones;
- AB 60 applicants cannot receive a REAL ID card.
