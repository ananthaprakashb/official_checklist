# 2027-28 FAFSA beta status

As verified August 31, 2026:

- Beta 2 is open for students and contributors to request participation through StudentAid.gov/joinbeta;
- an accepted beta participant can submit an official 2027-28 FAFSA before public launch;
- participating in beta does not provide an aid advantage over other students;
- Federal Student Aid states that the 2027-28 FAFSA is planned for public release by October 1, 2026.

This source is intentionally short-lived because the public-release state can change quickly.
