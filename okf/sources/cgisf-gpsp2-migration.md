# CGI San Francisco GPSP 2.0 Migration Notice

Official notice describing the current GPSP 2.0 application flow for passport-related services.

The current bundle relies on this notice for a critical pre-submission guardrail: the applicant must upload an ICAO-compliant photograph, scanned signature, and required supporting documents in the Government of India portal before mailing/submitting the application to VFS.
