# CGI San Francisco Tatkaal Passport Services

Official San Francisco consular guidance for Tatkaal passport re-issue eligibility, exclusions, processing, jurisdiction, and submission guidance.

For the adult re-issue preflight, this source is used to block automatic Tatkaal routing when the applicant falls into an excluded or ambiguous category.
