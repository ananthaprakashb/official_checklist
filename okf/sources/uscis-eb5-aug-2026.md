# EB-5 Immigrant Investor Program

EB-5 is an employment-based fifth-preference path but does not use Form I-140 or DOL PERM.

Current USCIS routing distinguishes standalone investors using Form I-526 and regional-center investors using Form I-526E. The Visa Bulletin separately tracks unreserved EB-5 and the rural, high-unemployment and infrastructure set-aside categories.

The generic employment-green-card preflight classifies these rows and visa-number gates but returns `NEEDS_AUTHORITATIVE_CONFIRMATION` for the investor-specific petition/evidence package until a dedicated EB-5 module is activated.
