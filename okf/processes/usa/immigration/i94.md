# I-94 Retrieval / Correction

1. `retrieve_record` — retrieve the latest electronic admission record from CBP.
2. `not_found` — retry using the exact identity/travel-document data used at admission; escalate under current CBP guidance if it still cannot be located.
3. `cbp_entry_error` — contact a CBP Deferred Inspection Site for review/correction of an error made at entry.
4. `uscis_issued_error` — use the USCIS correction/replacement route applicable to the USCIS-issued I-94.
5. `extend_or_change_status` — do not ask CBP to rewrite the admit-until date as a substitute for a USCIS extension/change-of-status filing.

The authority that created the record/error determines the recovery path.
