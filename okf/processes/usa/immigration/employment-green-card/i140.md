# Form I-140 Detailed Preflight

`classification → petitioner route → labor-certification alignment → category evidence → ability to pay → priority date / retention → premium processing → pending/RFE/NOID/decision → I-485 or NVC handoff`

## Filing gate

Before a new filing is treated as ready:

1. identify the exact E11/E12/E13/E21/E31/E32/EW3 or Schedule A underlying classification;
2. verify the petitioner is permitted for that classification;
3. verify the correct PERM/Schedule-A/no-labor-certification route;
4. verify the beneficiary evidence framework for the classification;
5. for job-offer classifications, verify the employer's ability-to-pay evidence is assembled;
6. resolve the petition's priority-date basis and any claimed earlier-date retention;
7. if premium processing is requested, use the current classification-specific I-907 window.

## Pending/adverse-action gate

- `rfe` / `noid`: the exact USCIS notice controls every requested issue and the response deadline.
- `approved`: continue to the Visa Bulletin and I-485/NVC path; approval alone does not create visa-number availability.
- `denied`: read the actual decision notice before choosing appeal, motion, or refiling. Do not assume the beneficiary has standing to appeal an employer-filed petition.

A `READY` result means the encoded preflight gates pass; it does not predict USCIS approval.
