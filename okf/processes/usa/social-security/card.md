# Social Security Number & Card

Resolve the SSA action before preparing documents.

Primary branches:

1. request an SSN for the first time;
2. replace a lost/damaged card with unchanged information;
3. change a legal name or correct card information;
4. correct the underlying Social Security record;
5. update citizenship or immigration status;
6. request a child card;
7. respond to stolen-number / identity-theft concerns.

Document requirements vary by citizenship/noncitizen status and action. When evidence is required, use SSA's current original/issuing-agency-certified document rules. Noncitizen eligibility and unusual record corrections return authoritative confirmation rather than guessed eligibility.
