# Passport Adverse Action / Appeal

Use this process when the applicant is responding to passport refusal, impounding, revocation, or another appealable Passport Seva decision rather than submitting a routine Fresh/Re-issue application.

## Route

1. Capture the adverse action and authority/reference exactly as issued.
2. Run the [adverse-action router](../../../../decisions/india-us-passport-adverse-action-route.md).
3. Preserve appeal/review deadlines and the specific authority named in the official communication.
4. Do not create a replacement Fresh/Re-issue application as a workaround unless the deciding authority instructs the applicant to do so.

Because the operative requirements depend on the actual adverse-action notice, this branch remains `NEEDS_AUTHORITATIVE_CONFIRMATION` until that notice is reviewed.
