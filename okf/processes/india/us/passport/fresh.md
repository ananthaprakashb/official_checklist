# Fresh Ordinary Passport — USA

Use this process only after [service classification](../../../../decisions/india-us-passport-service-classification.md) resolves an **Ordinary Passport / Fresh** application.

## Classification gates

1. Confirm the applicant is seeking an ordinary Indian passport, not PCC, Emergency Certificate, Surrender, Diplomatic/Official Passport, or Identity Certificate.
2. Confirm the applicant has not previously held the same ordinary-passport category in a way that requires Re-issue.
3. Resolve adult/minor category and jurisdiction before collecting documents.
4. Run the current Passport Seva document-advisor branch for the applicant facts.

## Requirements

- [Fresh-passport documents](../../../../requirements/india-us-passport-fresh-documents.md)
- [Applicant category](../../../../decisions/india-us-passport-applicant-category.md)
- [Booklet/validity](../../../../decisions/india-us-passport-booklet-validity.md)
- [Processing route](../../../../decisions/india-us-passport-processing-route.md)
- [Fresh fees](../../../../fees/india-us-passport-fresh-fees.md)

## Submission

Follow [Indian passport and related-service submission routing](../../../../submission/india-us-passport-submission.md). Do not reuse a Re-issue checklist merely because the applicant already has another Indian identity/travel document.

## Final gate

Run [Indian passport preflight](../../../../validation/india-us-passport-preflight.md). A Fresh/Re-issue mismatch is a hard blocker.
