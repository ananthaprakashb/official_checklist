# Official links in process workflows

Every live process exposes official or official-contracted destinations so a user can continue the real task after classification.

- The process landing page shows a small set of official starting points.
- The preflight result filters links to the route selected by the applicant's answers.
- Source/provenance links remain authoritative references; direct work portals are additive and never replace source verification.
- Third-party read-through proxies are not presented as official destinations.

Examples include USCIS/myUSCIS, CEAC, DOL FLAG, CBP I-94, Government of India Passport Seva, and VFS India USA.
